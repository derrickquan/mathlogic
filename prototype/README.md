# Playable prototype

A browser prototype of the student loop, running on the real 200 pages of level
2A. Open `index.html` — no build step, no server, no dependencies.

Published as an artifact at https://claude.ai/artifact/Henkt1MhDJimgHDoBaydqC

## What is real

- The curriculum. `2A.data.js` is generated by `python -m curriculum generate`
  and carries all 4,000 problems. Regenerate it with the snippet at the bottom
  of this file if the level ever changes.
- The ink. Pointer Events with pressure, so an Apple Pencil in Safari gives the
  real stroke behaviour the product depends on.
- Every rule with a number in it: the 95% gate measured per hundred problems,
  `ceil(n * 0.05)` with a floor of 1, two failures dropping a packet, the
  two-rewrite ceiling, active time counting gaps under 90 seconds, corrections
  surviving as a queue that belongs to the student.
- The wording. Wrong and unreadable are worded and coloured differently on
  purpose, and this is the artefact for arguing about that wording.

## What is not

**Recognition.** A page with no server cannot read handwriting, and shipping a
bad classifier would have made the prototype about the classifier. So the ink is
captured for real and then you are shown it and asked what you wrote. That stand-in
is also, deliberately, the same interaction a facilitator uses to clear the
low-confidence review queue. Typing mode skips it and grades what you enter.

Also absent: any database, the facilitator console, a real nightly email, offline
capture, and the packet-sizing rule (it needs three consecutive in-centre packets,
which is not a sitting).

## Regenerating the data

```
python3 - <<'PY'
import json
from pathlib import Path
from curriculum import load_level, generate_level

pages = generate_level(load_level("2A"))
packed = [[p.operands["a"] * 10 + p.operands["b"] for p in pg.problems] for pg in pages]
Path("prototype/2A.data.js").write_text(
    "// Level 2A, generated by `python -m curriculum generate`. Do not hand-edit.\n"
    "// 200 pages x 20 problems. Each value packs one problem: a = v/10, b = v%10.\n"
    f"window.LEVEL_2A = {json.dumps(packed, separators=(',', ':'))};\n",
    encoding="utf-8")
PY
```
